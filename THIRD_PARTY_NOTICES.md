## Reference projects studied (no code or assets copied)

- **SUMO2Unity** — SimuTraffX-Lab, https://github.com/SimuTraffX-Lab/SUMO2Unity (code MIT, assets CC-BY per its README).
  Read for design ideas only (see `RESEARCH.md`). If you use SUMO2Unity in research, its authors ask you to cite:
  Mohammadi et al., *SUMO2Unity: An Open-Source Traffic Co-Simulation Tool to Improve Road Safety*, IEEE IV 2024,
  doi:10.1109/IV55156.2024.10588571.
- **SUMO-Web3D** — Sidewalk Labs, https://github.com/sidewalklabs/sumo-web3d (EPL-2.0). Read for design ideas only
  (server-owned TraCI loop, y-flip coordinate mapping, id-based reconciliation). The coordinate transform and everything
  else in `web/` and `atcs3d/` were written for this project.

3D models (cars, signals, trees, buildings) are generated procedurally from primitive geometry in `web/js/`; no external
models, textures or fonts are used.
